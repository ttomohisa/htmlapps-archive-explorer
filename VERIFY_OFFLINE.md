# Offline verification

1. Run `build-standalone.bat`.
2. Disconnect the network.
3. Open `dist/index.html` directly with `file://`.
4. Test a ZIP containing Stored and Deflate entries.
5. Test TAR, GZIP, and TAR.GZ.
6. Confirm search, filters, preview, Analysis, Notes, manifest export, and selected-file export.
7. Repeat the smoke test with `dist/index.self-extract.html`.
